# Боти-спостерігачі

<!-- i18n-source: docs/observers.md @ 6fc084f -->

> Цю сторінку перекладено з англійської; якщо вони розходяться, правильною є англійська версія. ([English](../../observers.md))

Боти Telegram лише для читання, які отримують копії сповіщень основного бота. Вони отримують підсумки, попередження і помилки, але не можуть керувати сесіями.

## <a id="setup"></a>Налаштування

1. Створи бота через [@BotFather](https://t.me/BotFather)
2. Відкрий чат із ботом і надішли `/start`
3. Дізнайся ID свого чату (надішли повідомлення, потім подивися `https://api.telegram.org/bot<TOKEN>/getUpdates`)
4. Задай `OBSERVER_BOTS` в оточенні aipager. Для aipager на передньому плані експортуй змінну перед `aipager start`; для служби systemd:

```sh
systemctl --user edit aipager    # додай у розділ [Service]:
# Environment=OBSERVER_BOTS=<bot_token>:<chat_id>
```

Кілька спостерігачів (через кому):

```
OBSERVER_BOTS=111:AAA_first:12345,222:BBB_second:67890
```

Формат `token:chat_id`: під час розбору роздільником вважається **остання** двокрапка (у токенах ботів уже є своя двокрапка).

5. Перезапусти aipager

## <a id="what-observers-receive"></a>Що отримують спостерігачі

Спостерігачі отримують ці сповіщення з **кожного чату, який обслуговує бот**, з кожного особистого чату і кожної групи, без фільтра: заводь спостерігача лише для чату, якому можна довірити все це. Кожне сповіщення приходить мовою того чату, звідки воно прийшло.

| Подія | Приклад |
|-------|---------|
| Завдання закінчено | `💬 x1 · Завершено (2:05, +12 -3)`: лише рядок результату, не сама відповідь; плюс повний лог файлом `.md`, якщо відповідь або картку довелося обрізати |
| Фонову роботу закінчено | `✅ x1 · Завершено (...)` або `⚠️ x1 · Завершено (...)`, якщо агент зник або кінця фонової команди так і не помічено |
| Помилка API | `⚠️ x1 · Сервери Anthropic перевантажені. Спробуй трохи згодом.` (без кнопки Повторити) |
| Попередження про контекст | `⚠️ x1 · Контекст заповнено на 82% - скоро стиснеться автоматично` |
| Стиснення триває | `🔄 x1 · Стискає розмову` |
| Стиснення закінчено | `📦 x1 · Розмову стиснуто: 82% → 4%` |
| Запит досі чекає | `⬆️ x1 · досі чекає на твою відповідь вище`, з дозволом або питанням, на яке він чекає |
| Сесія, що працює, довго мовчить | `⏳ x1 · ще працює (10 хвилин без новин)` |
| Повідомлення, яке Claude Code не прийняв | `⚠️ x1 · Claude Code не прийняв повідомлення` |
| Сесія завершилася | `🔴 x1 · Сесію завершено` |

## <a id="what-observers-dont-receive"></a>Чого спостерігачі НЕ отримують

- Анімацій робочої картки
- Оновлень викликів інструментів
- Запитів на дозвіл та їхніх кнопок (лише нагадування «чекає» вище каже, про що питає запит)
- Діалогів AskUserQuestion
- Будь-яких клавіатур чи кнопок

Спостерігачі не мають жодного стану: надсилання йде без очікування відповіді. Спостерігач зі збоєм ніколи не впливає на основного бота.
