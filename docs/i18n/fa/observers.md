# ربات‌های ناظر

<!-- i18n-source: docs/observers.md @ b12e978 -->

> این صفحه ترجمهٔ صفحهٔ انگلیسی است؛ اگر جایی با هم فرق داشتند، نسخهٔ انگلیسی درست است. ([English](../../observers.md))

ربات‌های تلگرامی فقط‌خواندنی که اعلان‌های ربات اصلی را تکرار می‌کنند. خلاصه‌ها، هشدارها و خطاها به آن‌ها می‌رسد، ولی نمی‌توانند سشن‌ها را کنترل کنند.

## <a id="setup"></a>راه‌اندازی

1. با [@BotFather](https://t.me/BotFather) یک ربات بسازید.
2. با ربات یک چت باز کنید و `/start` را بفرستید.
3. آیدی چت را پیدا کنید (یک پیام بفرستید و بعد `https://api.telegram.org/bot<TOKEN>/getUpdates` را باز کنید).
4. `OBSERVER_BOTS` را در محیط aipager تنظیم کنید. اگر aipager را خودتان در ترمینال اجرا می‌کنید، قبل از `aipager start` آن را export کنید؛ برای سرویس systemd:

<div dir="ltr">

```sh
systemctl --user edit aipager    # زیر [Service] اضافه کنید:
# Environment=OBSERVER_BOTS=<bot_token>:<chat_id>
```

</div>

چند ناظر (با کاما جدا کنید):

<div dir="ltr">

```
OBSERVER_BOTS=111:AAA_first:12345,222:BBB_second:67890
```

</div>

شکلش `token:chat_id` است؛ موقع خواندن، **آخرین** دونقطه جداکننده حساب می‌شود (خود توکن ربات یک دونقطه دارد).

5. aipager را ری‌استارت کنید.

## <a id="what-observers-receive"></a>ناظرها چه چیزهایی می‌گیرند

این اعلان‌ها از **همهٔ چت‌هایی که ربات در آن‌هاست** به ناظرها می‌رسد، از هر چت خصوصی و هر گروه، بدون هیچ فیلتری: فقط برای چتی ناظر بگذارید که همهٔ این‌ها را به آن می‌سپارید. هر اعلان به زبان چتی است که از آن آمده.

| رویداد | نمونه |
|-------|---------|
| کار تمام شد | `💬 x1 · تمام شد (۲:۰۵، +۱۲ -۳)`: فقط خط نتیجه، نه خود جواب؛ و اگر جواب یا کارت کوتاه شده باشد، لاگ کامل هم به‌شکل فایل `.md` |
| یک کار پس‌زمینه تمام شد | `✅ x1 · تمام شد (...)`، یا `⚠️ x1 · تمام شد (...)` وقتی یک ایجنت از بین رفته یا از یک دستور پس‌زمینه خبری نشده |
| خطای API | `⚠️ x1 · سرورهای Anthropic الان خیلی شلوغ‌اند. چند لحظه بعد دوباره امتحان کنید.` (بدون دکمهٔ «دوباره امتحان کن») |
| هشدار کانتکست | `⚠️ x1 · کانتکست ۸۲٪ پر شده - به‌زودی خودکار کامپکت می‌شود` |
| در حال کامپکت | `🔄 x1 · در حال کامپکت کردن گفتگو` |
| کامپکت تمام شد | `📦 x1 · گفتگو کامپکت شد: ۸۲٪ ← ۴٪` |
| درخواستی که هنوز منتظر است | `⬆️ x1 · هنوز بالاتر منتظر جواب شماست`، همراه با درخواست اجازه یا سؤالی که منتظرش است |
| سشنی که کار می‌کند ولی بی‌خبر مانده | `⏳ x1 · هنوز کار می‌کند (۱۲۰ دقیقه بی‌خبر)` |
| پیامی که Claude Code تحویل نگرفت | `⚠️ x1 · Claude Code پیام را تحویل نگرفت` |
| سشن بسته شد | `🔴 x1 · سشن بسته شد` |

## <a id="what-observers-dont-receive"></a>ناظرها چه چیزهایی نمی‌گیرند

- انیمیشن کارت در حال کار
- آپدیت‌های اجرای ابزارها
- درخواست‌های اجازه و دکمه‌هایشان (فقط یادآوری «هنوز منتظر» بالا می‌گوید درخواست دربارهٔ چیست)
- سؤال‌های AskUserQuestion
- هیچ کیبورد یا دکمه‌ای

ناظرها هیچ وضعیتی نگه نمی‌دارند: پیام فرستاده می‌شود و تمام. اگر یک ناظر کار نکند، روی ربات اصلی اثری ندارد.
