# بوتات المراقبة

<!-- i18n-source: docs/observers.md @ b12e978 -->

> هذه الصفحة مترجمة عن الإنجليزية؛ إذا اختلفت النسختان، فالنسخة الإنجليزية هي الصحيحة. ([English](../../observers.md))

بوتات Telegram للقراءة فقط تتلقى نسخة من إشعارات البوت الرئيسي. تصلها الملخصات والتحذيرات والأخطاء، لكنها لا تستطيع التحكم في الجلسات.

## <a id="setup"></a>الإعداد

1. إنشاء بوت عبر [@BotFather](https://t.me/BotFather).
2. فتح دردشة مع البوت وإرسال `/start`.
3. معرفة معرّف الدردشة (إرسال رسالة، ثم فتح `https://api.telegram.org/bot<TOKEN>/getUpdates`).
4. ضبط `OBSERVER_BOTS` في بيئة aipager. إذا كان aipager يعمل في الواجهة، يُصدَّر المتغير (export) قبل `aipager start`؛ ولخدمة systemd:

<div dir="ltr">

```sh
systemctl --user edit aipager    # الإضافة تحت [Service]:
# Environment=OBSERVER_BOTS=<bot_token>:<chat_id>
```

</div>

عدة بوتات مراقبة (مفصولة بفواصل):

<div dir="ltr">

```
OBSERVER_BOTS=111:AAA_first:12345,222:BBB_second:67890
```

</div>

الصيغة هي `token:chat_id`: عند القراءة، يُعدّ **آخر** رمز نقطتين (:) هو الفاصل (توكن البوت نفسه فيه رمز نقطتين).

5. إعادة تشغيل aipager.

## <a id="what-observers-receive"></a>ما تتلقاه بوتات المراقبة

تتلقى بوتات المراقبة هذه الإشعارات من **كل دردشة يخدمها البوت**، كل دردشة خاصة وكل مجموعة، دون أي تصفية: لا يُعدّ بوت مراقبة إلا لدردشة جديرة بالثقة في كل ذلك. يصل كل إشعار بلغة الدردشة التي جاء منها.

| الحدث | مثال |
|-------|---------|
| انتهاء مهمة | `💬 x1 · انتهت (٢:٠٥، +١٢ -٣)`: سطر النتيجة فقط، دون الإجابة؛ مع السجل الكامل كملف `.md` حين تكون الإجابة أو البطاقة قد قُصّت |
| انتهاء عمل في الخلفية | `✅ x1 · انتهت (...)`، أو `⚠️ x1 · انتهت (...)` حين يختفي وكيل أو لا تُرى نهاية أمر في الخلفية |
| خطأ في الواجهة البرمجية | `⚠️ x1 · خوادم Anthropic مزدحمة جدًا الآن. يمكنك المحاولة بعد قليل.` (دون زر إعادة المحاولة) |
| تحذير السياق | `⚠️ x1 · امتلأ السياق بنسبة ٨٢٪ - سيُلخَّص تلقائيًا قريبًا` |
| يجري التلخيص | `🔄 x1 · يجري تلخيص المحادثة` |
| انتهى التلخيص | `📦 x1 · لُخّصت المحادثة: ٨٢٪ ← ٤٪` |
| طلب ما زال ينتظر | `⬆️ x1 · لا تزال بانتظار إجابتك في الأعلى`، مع طلب الإذن أو السؤال الذي ينتظره |
| جلسة تعمل بصمت | `⏳ x1 · لا تزال تعمل (١٢٠ دقيقة بلا أخبار)` |
| رسالة لم يأخذها Claude Code | `⚠️ x1 · لم يستلم Claude Code الرسالة` |
| انتهاء الجلسة | `🔴 x1 · أُغلقت الجلسة` |

## <a id="what-observers-dont-receive"></a>ما لا تتلقاه بوتات المراقبة

- حركة بطاقة العمل
- تحديثات استدعاءات الأدوات
- طلبات الإذن وأزرارها (وحده تذكير «ما زال ينتظر» أعلاه يذكر ما يطلبه الطلب)
- مربعات حوار AskUserQuestion
- أي لوحة مفاتيح أو أزرار

بوتات المراقبة بلا حالة تمامًا: تُرسل الرسائل دون انتظار رد. بوت مراقبة معطّل لا يؤثر أبدًا في البوت الرئيسي.
