# Боты-наблюдатели

<!-- i18n-source: docs/observers.md @ 6fc084f -->

> Эта страница переведена с английской; если они расходятся, верна английская версия. ([English](../../observers.md))

Боты Telegram только для чтения, которые получают копии уведомлений основного бота. Они получают итоги, предупреждения и ошибки, но не могут управлять сессиями.

## <a id="setup"></a>Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather)
2. Открой чат с ботом и отправь `/start`
3. Узнай ID своего чата (отправь сообщение, потом посмотри `https://api.telegram.org/bot<TOKEN>/getUpdates`)
4. Задай `OBSERVER_BOTS` в окружении aipager. Для aipager на переднем плане экспортируй переменную перед `aipager start`; для службы systemd:

```sh
systemctl --user edit aipager    # добавь в раздел [Service]:
# Environment=OBSERVER_BOTS=<bot_token>:<chat_id>
```

Несколько наблюдателей (через запятую):

```
OBSERVER_BOTS=111:AAA_first:12345,222:BBB_second:67890
```

Формат `token:chat_id`: при разборе разделителем считается **последнее** двоеточие (в токенах ботов уже есть своё двоеточие).

5. Перезапусти aipager

## <a id="what-observers-receive"></a>Что получают наблюдатели

Наблюдатели получают эти уведомления из **каждого чата, который обслуживает бот**, из каждого личного чата и каждой группы, без фильтра: заводи наблюдателя только для чата, которому можно доверить всё это. Каждое уведомление приходит на языке того чата, откуда оно пришло.

| Событие | Пример |
|-------|---------|
| Задача закончена | `💬 x1 · Завершено (2:05, +12 -3)`: только строка результата, не сам ответ; плюс полный лог файлом `.md`, если ответ или карточку пришлось обрезать |
| Фоновая работа закончена | `✅ x1 · Завершено (...)` или `⚠️ x1 · Завершено (...)`, если агент пропал или конец фоновой команды так и не был замечен |
| Ошибка API | `⚠️ x1 · Серверы Anthropic перегружены. Попробуй чуть позже.` (без кнопки Повторить) |
| Предупреждение о контексте | `⚠️ x1 · Контекст заполнен на 82% - скоро сожмётся автоматически` |
| Сжатие идёт | `🔄 x1 · Сжимает переписку` |
| Сжатие закончено | `📦 x1 · Переписка сжата: 82% → 4%` |
| Запрос всё ещё ждёт | `⬆️ x1 · всё ещё ждёт твоего ответа выше`, с разрешением или вопросом, которого он ждёт |
| Работающая сессия долго молчит | `⏳ x1 · всё ещё работает (10 минут без новостей)` |
| Сообщение, которое Claude Code не принял | `⚠️ x1 · Claude Code не принял сообщение` |
| Сессия завершилась | `🔴 x1 · Сессия завершена` |

## <a id="what-observers-dont-receive"></a>Чего наблюдатели НЕ получают

- Анимации рабочей карточки
- Обновления вызовов инструментов
- Запросы разрешения и их кнопки (только напоминание «ждёт» выше говорит, о чём спрашивает запрос)
- Диалоги AskUserQuestion
- Какие-либо клавиатуры или кнопки

У наблюдателей нет никакого состояния: отправка идёт без ожидания ответа. Наблюдатель со сбоем никогда не влияет на основного бота.
