# 관찰 봇

<!-- i18n-source: docs/observers.md @ b12e978 -->

> 이 페이지는 영어 문서를 번역한 거예요. 내용이 서로 다르면 영어 문서가 맞아요. ([English](../../observers.md))

메인 봇 알림의 사본을 받는 읽기 전용 Telegram 봇이에요. 요약, 경고, 오류를 받지만 어떤 세션도 조종할 수 없어요.

## <a id="setup"></a>설정

1. [@BotFather](https://t.me/BotFather)로 봇을 하나 만들어요
2. 그 봇과 채팅을 열고 `/start`를 보내요
3. 채팅 ID를 찾아요(메시지를 하나 보낸 뒤 `https://api.telegram.org/bot<TOKEN>/getUpdates`를 열어요)
4. aipager 환경에 `OBSERVER_BOTS`를 설정해요. aipager를 포그라운드에서 실행한다면 `aipager start` 전에 export하고, systemd 서비스라면:

```sh
systemctl --user edit aipager    # [Service] 아래에 추가:
# Environment=OBSERVER_BOTS=<bot_token>:<chat_id>
```

관찰 봇 여러 개(쉼표로 구분):

```
OBSERVER_BOTS=111:AAA_first:12345,222:BBB_second:67890
```

형식은 `token:chat_id`예요. **마지막** 콜론을 구분자로 써서 읽어요(봇 token 안에 이미 콜론이 하나 있어요).

5. aipager를 재시작해요

## <a id="what-observers-receive"></a>관찰 봇이 받는 것

관찰 봇은 **봇이 서비스하는 모든 채팅**에서 이 알림들을 받아요. 모든 개인 채팅과 모든 그룹이 포함되고, 걸러지는 것은 없어요. 이 모든 내용을 맡겨도 되는 채팅에만 관찰 봇을 설정하세요. 알림은 각각 그것이 온 채팅의 언어를 써요.

| 이벤트 | 예시 |
|-------|---------|
| 작업이 끝남 | `💬 x1 · 완료 (2:05, +12 -3)`: 결과 줄만 오고 답변은 오지 않아요. 답변이나 카드가 잘렸을 때는 전체 로그가 `.md` 파일로 함께 와요 |
| 백그라운드 작업이 끝남 | `✅ x1 · 완료 (...)`, 또는 에이전트가 사라졌거나 백그라운드 명령이 끝나는 것을 끝내 보지 못했을 때 `⚠️ x1 · 완료 (...)` |
| API 오류 | `⚠️ x1 · Anthropic 서버가 지금 매우 바빠요. 잠시 후 다시 시도해 주세요.` (다시 시도 버튼 없음) |
| 컨텍스트 경고 | `⚠️ x1 · 컨텍스트 82% 사용 - 곧 자동으로 압축해요` |
| 대화 압축 중 | `🔄 x1 · 대화 압축 중` |
| 대화 압축됨 | `📦 x1 · 대화 압축됨: 82% → 4%` |
| 아직 기다리는 요청 | `⬆️ x1 · 위에서 아직 답변을 기다리고 있어요`, 기다리고 있는 권한 요청이나 질문과 함께 |
| 작업 중이지만 조용한 세션 | `⏳ x1 · 아직 작업 중 (120분째 소식 없음)` |
| Claude Code가 가져가지 않은 메시지 | `⚠️ x1 · Claude Code가 메시지를 받지 않았어요` |
| 세션 종료 | `🔴 x1 · 세션 닫힘` |

## <a id="what-observers-dont-receive"></a>관찰 봇이 받지 않는 것

- 작업 카드 애니메이션
- 도구 호출 업데이트
- 권한 요청과 그 버튼(요청이 무엇을 묻는지는 위의 “아직 기다리는” 알림만 알려 줘요)
- AskUserQuestion 대화 상자
- 모든 키보드와 버튼

관찰 봇은 상태를 전혀 저장하지 않아요. 메시지를 보낸 뒤 응답을 기다리지 않아요. 고장 난 관찰 봇이 메인 봇에 영향을 주는 일은 절대 없어요.
